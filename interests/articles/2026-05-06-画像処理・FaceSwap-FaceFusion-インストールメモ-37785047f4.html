FaceFusion インストールメモ

概要

Mac mini M4 に FaceFusion をローカル導入した。

  • インストール先: [内部パス]
  • FaceFusion: 3.6.1
  • Git commit: 5b7d145
  • Python: Homebrew Python 3.12.13
  • 仮想環境: [内部パス]
  • FFmpeg: Homebrew ffmpeg@7 / 7.1.4
  • ONNX Runtime providers: CoreMLExecutionProvider, AzureExecutionProvider, CPUExecutionProvider

起動方法

Finder から次をダブルクリック:

``text [内部パス] ``

またはターミナルで:

``zsh cd ~/Applications/facefusion source .venv/bin/activate python facefusion.py run --execution-providers coreml cpu ``

起動後、ブラウザで以下を開く:

``text http://127.0.0.1:7860/ ``

補足

  • Conda は Miniconda 導入後に Anaconda channel の Terms of Service 承認が必要だったため、今回は自動承認せず Homebrew Python + venv で構築した。
  • 初回起動時に必要な ONNX モデル類が自動ダウンロードされる。
  • 実在人物の顔を使う場合は、本人同意がある素材のみを使い、公開時は AI 加工であることを明示する。
