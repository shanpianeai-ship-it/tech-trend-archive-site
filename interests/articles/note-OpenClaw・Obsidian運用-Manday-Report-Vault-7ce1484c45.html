Manday Report Vault

このフォルダはManday生成レポートのObsidian管理用Vaultとして使う想定です。

主要フォルダ

  • Indexes/ — レポート索引。Reports Index.md は自動生成。
  • Topics/ — テーマ別の起点ノート。
  • Templates/ — レポート用テンプレート。
  • Attachments/ — 添付ファイル置き場。

運用

  • 新規レポートは原則このVault直下にMarkdownで保存されます。
  • キュー完了時に [内部パス] が索引を更新します。
  • 手動更新する場合:

``bash python3 [内部パス] ``

Obsidianで開く

Obsidian本体をインストール後、このフォルダ [内部パス] をVaultとして開いてください。

Backup note

Syncはバックアップではありません。Time Machine、Git、Local Backup pluginなどのいずれかを別途使うことを推奨します。
