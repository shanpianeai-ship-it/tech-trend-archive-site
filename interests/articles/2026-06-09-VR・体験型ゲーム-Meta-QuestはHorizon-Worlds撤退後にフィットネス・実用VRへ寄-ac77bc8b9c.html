Meta QuestはHorizon Worlds撤退後にフィットネス・実用VRへ寄るのか

要約

Meta Questは「Horizon Worlds中心のメタバース端末」から、「ゲーム、フィットネス、軽い実用用途を選んで使うスタンドアロンVR端末」へ寄っていると見るのが自然。

Horizon Worldsについては、2026年2月から3月にかけて、Quest VRからの切り離し、VR版終了方針、そしてCTO発言による一部継続への反転が続いた。最終的には完全撤退ではなくなったが、MetaがHorizon Worldsの主戦場をモバイルへ移し、Quest側では開発者ゲームやアプリを前面に出す方向へ変えたことは変わらない。

一方で、SupernaturalはMeta傘下での停止ムードから独立会社として復活し、2026年秋にQuest Storeへ戻る予定を掲げている。これは「Metaが自社でメタバースを抱え込む」より、「強い用途を持つアプリがQuest上で残る」方向を示す材料になる。

なぜ今見る価値があるか

Meta Questを使う側にとって、Horizon Worldsの扱いは端末の将来像を読むサインになる。

かつてのQuestは、Metaのメタバース構想と強く結びつけて語られた。しかし2026年時点では、Horizon Workroomsの終了、Horizon Worldsのモバイル優先化、Supernaturalの独立復活が並んでいる。これは「巨大な仮想空間に人を集める」より、「ゲーム、運動、リモートデスクトップ、PC VR、個別アプリを必要な時に使う」方向への整理に見える。

個人の用途では、Questを買い替えるか、使い続けるか、運動用に習慣化するかを考える材料になる。Eleven Table Tennisのような継続型スポーツVRを使っているなら、Horizon Worldsの盛衰よりも、運動・ゲーム・MRアプリの実用性を見た方が判断しやすい。

調査メモ

1. Horizon Worldsは「完全終了」ではなく「VR中心ではなくなった」

Metaは2026年にHorizon WorldsとQuest VRの関係を大きく見直した。TechCrunchは、MetaがHorizon Worldsを「ほぼモバイル中心」へ移し、Quest VRプラットフォームから明確に分ける方針を示したと報じている。

その後、2026年3月にはHorizon WorldsのVRサポート終了が告知されたが、Meta CTOのAndrew Bosworth氏がVRでの継続を示し、Meta広報もそれを確認した。つまり、単純に「Horizon WorldsがQuestから消えた」とは言い切れない。

ただし重要なのは、反転後もMetaの優先順位が変わった点。TechCrunchによれば、Bosworth氏はHorizonのモバイル側により良いプロダクトマーケットフィットがあると説明している。Quest側の中心がHorizon Worldsではなくなる、という読みは維持してよい。

2. Questは「メタバース入口」より「専用用途の実行端末」に近づく

Horizon Worldsの後退と並行して、Horizon Workroomsも2026年2月16日に終了したと複数媒体が報じている。法人向け・会議向けVRも、Metaが単独アプリとして強く押し続ける形ではなくなった。

この流れを見ると、MetaがQuestを「すべての人が常駐する仮想空間」へ一本化する構図は弱くなっている。むしろ今後のQuestは、次のような用途別に価値を測る端末になる。

  • ゲーム: Beat Saber、Eleven Table Tennis、VR専用タイトル、PC VR
  • フィットネス: Supernatural、Les Mills系、ボクシング・卓球・ダンス
  • 実用: リモートデスクトップ、映像視聴、MR作業、短時間の集中環境
  • ソーシャル: VRChatや個別コミュニティ。ただしMeta公式空間一強ではない

「Metaが作る巨大空間に行くための機械」ではなく、「良いアプリがあるなら使う機械」と見る方が現実に近い。

3. Supernatural復活はフィットネスVRの強さを示す

Supernatural公式サイトは、同サービスが独立会社として復活し、2026年秋にQuest Storeへ戻る予定だと案内している。公式ページでは、コーチの復帰、新ワークアウト、コミュニティ重視、Founding Member価格なども示されている。

Android Centralも、Supernaturalの復活を「Meta管理ではなく、元のチームが独立して再始動する」動きとして取り上げている。TechCrunchも、MetaがSupernaturalを単に終了させるのではなく、独立会社へスピンアウトさせる流れを報じている。

ここで見えるのは、VRフィットネスがメタバース構想より小さい市場でも、習慣化とコミュニティの強さを持ちうること。毎日または週数回使う理由が明確で、身体感覚として成果が分かるため、Questの用途としてはかなり強い。

4. Eleven Table Tennis利用者にはむしろ追い風

個人がすでにEleven Table Tennisを運動兼ゲームとして見ているなら、Horizon Worldsの後退は大きなマイナスではない。

むしろQuestのホームやストアで、Worldsよりも開発者ゲームや個別アプリが前に出るなら、スポーツVR・運動VRを探しやすくなる可能性がある。Metaが自社ソーシャル空間を最優先に押し込むより、用途別アプリの発見性が上がる方が、日常ユーザーにはありがたい。

今後のチェック観点は、Horizon Worldsの利用可否より以下になる。

  • Quest 3 / 3Sで快適に動く運動アプリが増えるか
  • MR対応で部屋の安全確認がしやすくなるか
  • サブスク型フィットネスの価格と継続価値が見合うか
  • Eleven Table Tennis以外に、週2回以上続くタイトルがあるか
  • PC VRやリモートデスクトップなど、運動以外の実用時間が増えるか

5. 実用VRは「長時間常駐」ではなく「短時間で目的を終える」が現実的

Questを実用端末として見る場合、仕事を丸一日VRでやる発想はまだ強引。装着感、目の疲れ、入力効率、首肩への負担がある。

一方で、短時間の用途なら成立しやすい。

  • 20〜40分の運動
  • 15分の卓球・ボクシング・ダンス
  • 大画面での動画視聴
  • PC画面を広げて短時間の確認作業
  • 旅行・住宅・3Dモデルなどの空間確認

つまり、Questの価値は「毎日何時間も被る」より、「スマホやPCでは得にくい身体性・没入感がある用途だけ使う」に寄せる方が判断を誤りにくい。

個人向けの読みどころ

個人向けには、Questをメタバース期待で評価しない方がよい。

評価軸は以下で十分。

  1. Eleven Table Tennisを週2〜3回続けられるか
  2. Supernatural復活後、月額または年額に見合う運動習慣になるか
  3. Quest 3 / 3SのMR機能で、部屋の安全性と装着ストレスが許容できるか
  4. VRChatやHorizon Worldsのようなソーシャル空間に時間を使いたいか
  5. PC作業・動画視聴など、運動以外の使い道が週1回以上あるか

結論としては、「Questは実用VRへ寄るが、万能な作業端末になるというより、運動とゲームを軸にした短時間集中端末として見る」のが妥当。すでにEleven Table Tennisが続いているなら、Questはまだ十分に使い道がある。

注意点

Horizon Worldsまわりは、2026年2月から3月にかけて方針が揺れている。古い記事だけを見ると「VR版完全終了」と読めるが、その後にMeta CTO発言で一部継続へ反転している。したがって、本レポートでは「Horizon WorldsはQuestの中心ではなくなったが、完全撤退とは断定しない」と整理する。

運動用途については医療的助言ではない。痛み、しびれ、めまい、持病、強い疲労感がある場合は、医療職や専門家に確認すること。VR運動では周囲の障害物、床、照明、壁との距離を必ず確認し、肩・手首・首に違和感が出たら中止する。

Supernaturalの復活予定や価格は、2026年6月9日時点の公開情報。リリース時期、対応地域、Quest Storeでの提供条件は変わる可能性がある。
