2026-07-15 SAP / ERP importance: high
Summary

2026年7月のSAP Security Patch Dayは16件の新規ノートと既存更新を含み、公開経路や権限境界をまたぐ脆弱性の優先対応が重要。SAP基盤の優先順位付けを先に決める価値が高い情報です。

SAP July 2026 Security Patch Day: まず先に見るべきライン

要約

7月のSAP Security Patch Dayは、ABAP/Approuter/Commerce Cloud/HANA関連を含む複数製品で、RCE・権限判定・設定周りの脆弱性に関するSecurity Noteを集中的に公開しています。

記事冒頭で言及されているように、月例として公開されたノートには優先度の高い項目が混在しているため、外部到達性・認証境界への影響を軸に棚卸しを先に行い、CMDB上で適用順を決めることが有効です。

背景

SAP Security Patch Day - July 2026では16件の新規Security Noteと1件のGithub security advisoryが公開され、各Noteに対してCVE参照が付与されています。SAPからは「優先的に反映する」ことが繰り返し強調されており、特に次の3軸が実務上重要です。

  • SAP NetWeaver AS ABAP/APJrouter/AS Java/Web Container
  • SAP Commerce Cloud / SAP HANA系サービス
  • SAP S/4HANA関連の権限チェック系脆弱性

本日は夜枠ポールの1時間後時点で有効票がなく、選定ルールにより候補6を採用しました。

今回の候補から読み取る実務ポイント

  • SAP NetWeaver AS ABAP (CVE-2026-44747): メモリ破壊系脆弱性は長時間運用中の基盤不安定化を起こす可能性があり、対象コンポーネント検出と適用可否が最優先。
  • SAP Approuter (CVE-2026-27690 / 44745): リクエスト処理の脆弱性は認可判定経路に直結するため、外向け認証ゲートの監査と到達制御の確認が必要。
  • SAP S/4HANA権限処理 (CVE-2026-44768 / 44770 ほか): 権限チェック系は侵害時の二次被害が大きいため、重要トランザクションの監査ログ整備と暫定制限を先に検討。
  • SAP Commerce Cloud / SAP Integration Suite / HANA XSA: 改修範囲が広く、運用管理者が実施箇所を見落としやすい。利用しているかの有無だけでなく、実際の到達経路を照合する。

参考となる初期アクション（自分向け）

  1. CMDBで対象システムを抽出し、SAP NetWeaver AS ABAP/Java, S/4HANA, Approuter, Commerce Cloud, Integration Suite の有無を確認。
  2. 14日版/7月版のSecurity Note番号で対象システムを突合し、外部公開経路があるものを先行実施。
  3. 権限処理関連CVEは業務停止リスクを考慮しつつ、監査ログ・暫定制御（アクセス制限/トークンローテーション）をセットで準備。
  4. 適用後は脆弱性修正前後で不正応答やログ異常が増えていないか、監視ルールを1～2日追加して確認。

自分向けメモ

  • 月例パッチでも「外部到達性」が高い領域は緊急対応級に扱う。
  • SAPでは同時適用対象に S/4HANA と Approuter が混ざると、業務影響より先に監査対応が必要になることがある。
  • CTF/開発テストと本番のカーネル・基盤バージョンを統一し、Patch Day対応漏れを最小化する。
  • 選定: 同票なし であった分、今夜は「実務影響が大きく、一次情報が明確」なSAP公式パッチ情報を優先して読み切る。
